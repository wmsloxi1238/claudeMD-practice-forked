## 작성 규칙
- 월별 폴더(`Jan`, `Feb`, ..., `May`, ...) 안에 `YYYY-MM-DD.md` 파일로 작성
- 각 파일은 다음 4개 섹션 포함: 학습 목표 / 새로 배운 내용 / 도전 과제와 해결 / 회고
- 회고와 문제 해결 부분에 집중하여 작성
- 주말/공휴일에 학습하지 않은 날은 기록을 생략해도 무방
- 코드 스니펫은 언어 태그를 붙여 가독성을 높일 것 (예: ` ```bash `)
